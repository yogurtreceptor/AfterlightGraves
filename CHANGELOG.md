# Changelog

## 1.0.0 - 2026-09-19

- Store complete death inventories and XP in durable per-grave files.
- Add shared recovery, with owner-only recovery available through configuration.
- Add the non-OP `/graves` command with dimension, coordinates, and same-world distance.
- Add a protected compound grave marker and enlarged recovery hitbox.
- Preserve partially recovered graves when a player's inventory is full.
- Verify loading, restart persistence, shared recovery, full recovery, TNT,
  fire, and lava behaviour on Paper 26.3 build 8 and Java 25.
